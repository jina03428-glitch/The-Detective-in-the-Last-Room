# 《마지막 객실의 탐정》 게임 대사 스크립트

> 시나리오 정본용 내부 문서. 범인, 사건의 진상과 모든 엔딩에 대한 스포일러를 포함한다.  
> 2026-11-24 개정본은 아직 `detective-game` 코드에 반영하지 않는다. 문서 검수 완료 뒤 한 번에 구현한다.

이 문서는 1897년 런던행 야간열차에서 일어난 사건을 시간순으로 재구성한 전체 게임 스크립트다. 1회차에는 아서가 탐정이라고 믿는 시점을 따라가고, 2회차에는 경찰 조사실에서 압수 증거와 추가 진술을 통해 같은 밤을 다시 구성한다. 모든 조사와 심문은 자유 입력 없이 고정 선택지로 진행한다.

> 2026-11-24 인물 말투 개정: 캐릭터 프로필의 성격·계층·직업과 감정 단계를 대사에 반영했다. 이 개정은 시나리오 문서에만 적용하며 게임 코드에는 아직 반영하지 않는다.

# 1. 표기 규칙

| 표기 | 용도 |
|---|---|
| `[BG]` | 배경 이미지 전환 |
| `[BGM]` | 배경음악 시작·변경·정지 |
| `[SFX]` | 효과음 |
| `[CG]` | 사건 일러스트 또는 기억 장면 |
| `[SPRITE]` | 인물 스프라이트와 표정 |
| `[SYSTEM]` | UI 안내, 증거 획득, 플래그 변경 |
| `[NARRATION]` | 화면 밖 서술 |
| `[CHOICE]` | 플레이어가 선택하는 고정 대화·행동·지목 |
| `[REQUIRE]` | 장면을 열기 위한 조건 |
| `[FLAG]` | 이후 장면에 영향을 주는 상태값 |
| `[CAMERA]` | 화면 구도, 줌과 시선 이동 |
| `[ACTING]` | 표정만으로 부족한 손짓·호흡·시선 등 연기 지문 |
| `[BEAT]` | 대사의 의미가 바뀌는 짧은 정적 |

인물명 뒤의 괄호는 권장 표정이다. 예: `엘리너(의심)`, `아서(두통)`.

지문은 플레이어가 화면에서 확인할 수 있는 행동만 현재형으로 적는다. `불안하다`처럼 내면을 직접 쓰지 않고 `장갑 낀 엄지로 서류 모서리를 세 번 문지른다`처럼 보이는 행동으로 바꾼다. 비밀과 진상은 해금 전 지문에서도 단정하지 않는다. 한 대사 블록은 가능하면 두 문장 이내로 유지하고, 긴 설명은 질문 선택지로 나눈다.

## 선택형 대화 공통 규칙

1. 한 장면에서 보여 주는 심문·추리 선택지는 최대 3개다. 질문 목록을 전부 소진하는 방식은 사용하지 않는다. 장면 이동용 허브, 돌아가기 버튼과 최종 용의자 명단은 예외로 한다.
2. 각 대화 장면에는 `상대가 숨기는 것`, `플레이어가 얻어야 할 것`, `장면을 끝내는 반전`을 하나씩 둔다.
3. 첫 선택은 인물의 태도를 드러내고, 두 번째 선택은 증거 또는 모순을 겨냥한다. 세 번째는 물러나거나 다른 가설을 택하는 선택이다.
4. 핵심 진술은 `주장 → 증거 대질 → 진술 수정`의 세 단계로 얻는다. 질문을 눌렀다는 이유만으로 정답을 말하게 하지 않는다.
5. 한 번의 심문에서 비밀을 전부 캐지 않는다. 새 물증을 얻은 뒤 다시 만나면 이전 태도와 대사가 달라진다.
6. 이미 확인한 선택지는 회색 체크로 남기되, 반복 선택은 새 정보 대신 인물의 짧은 반응만 보여 준다.
7. 관련 증거가 없으면 증거 선택지를 숨긴다. 잠긴 정답을 미리 보여 주지 않는다.
8. 선택지 문구는 가능하면 질문이 아니라 아서의 가설로 쓴다. 예: `시계를 만진 사실을 숨겼다`, `장갑은 누군가 옮겼다`, `아직 판단을 보류한다`.
9. 대화가 끝날 때마다 새 장소, 새 물증, 다른 인물의 개입 또는 시간 압박 중 하나가 발생해야 한다.
10. 1회차의 필수 정보는 유지하되, 네 인물의 메뉴를 반복해서 소진하지 않는다. 사건 중 일어나는 대질 장면에 분산한다.

## 캐릭터별 대사 기준

| 인물 | 대사 리듬과 말버릇 | 피해야 할 표현 |
|---|---|---|
| 아서 | 결론을 먼저 말하고 근거를 뒤에 붙인다. 침착할 때는 단정한 존댓말, 기억이 흔들릴수록 짧은 혼잣말과 자기 질문이 늘어난다. | 모든 사실을 보고서처럼 한 번에 설명하는 말 |
| 엘리너 | 짧고 정확한 존댓말. 질문의 의도를 먼저 확인하고, 모르는 사실은 단정하지 않는다. 화가 날수록 소리치지 않고 목소리가 낮아진다. | 감정을 길게 해설하거나 근거 없이 확언하는 말 |
| 마거릿 | 정중하지만 차갑고 우회적이다. 가족 이야기가 나오면 질문자의 자격을 따지고, 감정이 새면 즉시 체면을 회복한다. | 거친 욕설, 지나치게 직접적인 고백 |
| 토머스 | 짧고 무뚝뚝하며 시각·규정·열쇠 수를 정확히 말한다. 압박받으면 직책과 책임 범위를 반복한다. | 추상적인 추리나 장황한 감상 |
| 조너선 | 질문에 질문으로 답하고 상대의 표현을 그대로 인용한다. 냉소는 가볍게, 관찰 사실은 날카롭게 말한다. | 확증 없이 범인을 단정하는 말 |
| 사무엘 | 느리고 조심스럽다. 자신이 본 사실과 해석을 구분하며, 비난 대신 질문을 건넨다. | 단정적인 설교와 공격적인 추궁 |
| 하그리브스 | 기록과 회상에서만 등장한다. 상대를 환자나 학생처럼 가르치며 자신의 선택을 ‘과학의 요구’로 포장한다. | 스스로 악행을 인정하는 노골적인 대사 |

대사는 정보 전달보다 인물의 반응을 먼저 보여 준다. 긴 진술은 `[BEAT]`, 손동작과 시선 지문으로 나누고, 같은 정보를 서로 다른 인물이 같은 문장 구조로 반복하지 않는다.

## 재미 강화를 위한 장면 리듬

사건의 사실과 세 엔딩은 바꾸지 않는다. 플레이어가 정보를 받는 순서와 대화의 충돌 방식을 바꾼다.

| 단계 | 플레이어 경험 | 장면 끝에 남길 것 |
|---|---|---|
| 1. 이상 징후 | 설명보다 먼저 깨진 찻잔, 잠긴 문과 멈춘 시계를 본다 | `이 죽음은 평범하지 않다` |
| 2. 첫 가설 | 편지칼·시계·밀실 중 사망 원인을 직접 고른다 | 시계라는 첫 작은 정답과 성취감 |
| 3. 인물 충돌 | 한 명씩 독립 심문하지 않고 서로의 말을 듣고 반박하게 한다 | 거짓말의 존재와 살인 동기의 차이 |
| 4. 모순 대질 | 진술 한 문장과 물증 하나를 플레이어가 연결한다 | NPC의 태도 변화와 새 동선 |
| 5. 역공 | NPC가 아서의 신분·수첩·사전 지식을 되묻는다 | 탐정 자신도 안전하지 않다는 불안 |
| 6. 물리적 위기 | 정전, 흔들림과 역 도착 예고가 조사를 끊는다 | 제한 시간과 기억 파편 |
| 7. 공개 재구성 | 플레이어가 증거 순서를 골라 모두 앞에서 사건을 재현한다 | 엘리너의 자백과 남는 모순 |
| 8. 재해석 | 2회차는 같은 질문을 반복하지 않고 1회차 단서의 의미를 뒤집는다 | `탐정이 곧 마지막 용의자`라는 발견 |

### 1회차 긴장 곡선

`탐정이라는 안도 → 시신 발견 → 시계 추리 성공 → 용의자들의 거짓말 → 아서의 신분 의심 → 엘리너 가방의 열쇠 → 아서의 사전 지식 폭로 → 정전과 기억 침입 → 공개 추리 → 너무 완전한 자백`

### 장면 작성 고정 규칙

- 3분 이상 새 정보가 없으면 사건을 진행시키는 행동을 넣는다.
- 설명이 세 문장을 넘으면 다른 인물의 반박, 소리, 행동 또는 선택지로 끊는다.
- 모든 장면은 시작 2문장 안에 질문이나 위험을 제시한다.
- 장면 마지막 대사는 설명을 닫는 문장이 아니라 다음 질문을 여는 문장으로 쓴다.
- 플레이어가 맞힌 작은 추리는 즉시 인물 반응이나 새 증거로 보상한다.
- 오답은 실패 문구 대신 인물의 성격이 드러나는 짧은 반박으로 처리한다.

```text
대화 메뉴 예시
[1] “당신은 시계를 만진 사실을 숨겼다.” [공격적 대질]
[2] “장갑은 누군가 건조대에서 옮겼다.” [다른 가설]
[3] “지금은 판단을 보류하겠다.” [대화 종료]
```

# 3. 사건의 실제 시간표

플레이어에게 처음부터 공개하지 않는 제작 기준 시간표다.

| 시각 | 실제 사건 |
|---|---|
| 19:35 | 아서가 위조 전보를 저녁 서신 묶음에 넣는다. |
| 19:40 | 아서가 위조 탐정 신분으로 열차에 탑승한다. |
| 19:55 | 아서가 토머스에게 7호 객실과 열쇠 관리 방식을 안내받는다. |
| 20:00 | 열차가 런던을 향해 출발한다. |
| 20:25 | 하그리브스가 식당칸으로 이동하며 회중시계를 객실에 둔다. |
| 20:40 | 과거 실험 후유증이 심해지며 아서의 새로운 기억이 불완전하게 형성되기 시작한다. 연결 통로를 지나며 건조대의 젖은 장갑 한 짝을 가져간다. |
| 20:41 | 토머스가 승무원실을 비운 사이 아서가 예비 열쇠를 가져간다. |
| 20:42 | 아서가 빈 7호 객실에서 진짜 시계를 가짜 시계로 바꾸고 젖은 장갑을 현장에 둔다. 20시 45분 전에 객실을 빠져나온다. |
| 20:46 | 하그리브스가 객실로 돌아온다. |
| 20:45 | 하그리브스가 시계가 평소보다 몇 분 어긋난 것을 발견한다. 시간 오차를 참지 못하는 그는 늘 시계를 관리하던 엘리너를 부른다. |

5. NPC의 비밀과 거짓말은 해당 증거를 얻은 뒤에만 해금한다.
6. 1회차에는 아서가 진범이라고 직접 확정하는 선택지를 보여주지 않는다.
7. 실패 엔딩에서는 아서의 진범 사실을 공개하지 않는다.
8. 2회차에도 잘못된 인물 지목은 새로운 엔딩으로 분기하지 않고 증거 반박 후 선택 화면으로 돌아간다.
9. 약 복용과 치료 경험을 살인의 원인으로 표현하지 않는다.
10. 회중시계는 9시 10분에 시간 연동 잠금쇠가 풀리고 연결식 타격침이 뒷판 밖으로 짧게 돌출되는 세계관 내부의 장치로 통일한다. 탄환이나 화약은 사용하지 않으며, 실제 제작에 필요한 치수·재료 조합·조립 순서는 묘사하지 않는다.
11. 엘리너의 대리 자백은 올바른 희생으로 미화하지 않는다. 2회차의 진상 공개는 아서를 복수 속에 혼자 남겨 두지 않기 위한 선택으로 다룬다.
12. 진엔딩은 살인 책임과 하그리브스의 연구 범죄를 모두 공개해야 성립한다.
13. 플레이어가 직접 방문하지 않은 장소의 증거는 자동으로 지급하지 않는다. 다른 인물이 대신 가져와 주는 방식도 사용하지 않는다.
14. 한 장소의 첫 조사에서는 새 증거를 하나만 확정한다. 같은 장소에 증거가 둘 이상 있으면 재방문, 입회자 확보 또는 선행 증거 제시로 조사 단계를 나눈다.
15. 열차 이동 화면에는 현재 위치, 이동 가능한 객차, 조사 완료 여부와 다음 역까지 남은 시간을 표시한다.
16. 승무원실·식당칸·객실칸·연결 통로·아서의 객실은 1회차 필수 방문 장소로 고정한다. 나머지 장소는 보조 단서와 추가 대사를 얻는 선택 조사로 둔다.
